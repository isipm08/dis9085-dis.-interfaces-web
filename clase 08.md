## Propiedades
¿A quién? -- selector -- etiquetas
- diferentes tipos:
1. etiquetas: ```<p><h1><a>``` estilos generales para todo el estilo
2. clases: ```.tarjeta <article class="tarjeta"></article>``` dar estilos especificos, uso en css
3. Id: ```#contacto <article id="contacto" class"tarjeta"> </article>``` identificar elemento o anclear navegación, linkear sitio, no usar en css
4. Descendientes: ```.tarjeta p {}``` se aplica a lo que está dentro de la clase tarjeta
5. Pseudoclase:```a:hover {}``` estado elemento
