## 01. Web como medio
- User experience: Dimensión invisible, organiza, comporta y siente un producto digital. "Funcione bien para quien lo usa"
  - arquitectura de la información
  - flujos de navegación
  - usabilidad
  - accesibilidad
  - investigación de necesidades del usuario
    
- User interface: Dimensión visible, capa visual, sensorial, usuario interactúa con esa estructura.
  - tipografía
  - color
  - componentes (botones, cards, inputs)
  - jerarquía visual
  - sistemas de diseño
    
- Interfaz de usuario: Transforma ciertas señales, imágenes, símbolos o acciones de un sistema para poder hacerlas comprensibles para el ser humano, permitiendo también al usuario dar instrucciones, ingresar y recibir información
  
- Navegador como soporte de diseño: El contenido web se adapta al espacio disponible
  - viewport: área visible de la página dentro de la pantalla del dispositivo
  - resolución: tamaño viewport se adapta a cada dispositivo (mobile, tablet, desktop)
    
- Diseño responsive: Hace que los sitios se vean y comporten de manera óptima en todos los dispositivos
  
- Breakpoints: Punto donde el contenido se "rompe" visualmente, cambiando estructura de la página
  
## 02. Interactividad
- "No todo es percepción visual"
- Feedback visual: Usuario necesita evidencia de que su acción fue registrada
- Microinteracciones: Pequeñas animaciones que guían y comunican
  
## 03. Accesibilidad
- Principio de diseño: Busca que cualquier persona, en cualquier contexto y con cualquier capacidad, pueda usar una interfaz
- Comprensible: Diseñar nuestro sitio de forma sencilla
  - Crea una estructura y un sistema de navegación consistente a lo largo de todo el sitio
  - Comunicación clara: Contenido fácil de entender, evitando el lenguaje complejo
  - Uso de una tipografía legible y tamaños de texto apropiados
  - Asegurar el contraste entre el color del texto y del fondo para garantizar que se pueda leer
  - Promueve la inclusión y la igualdad de oportunidades
