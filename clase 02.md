## Diseño de interfaz en Figma
- **¿Qué es un wireframe?**
 - Es un esquema visual que representa la estructura de una página web o aplicación móvil. Su propósito es solo definir el contenido y la posición de distintos elementos dentro de una aplicación digital. Esto incluye: navbar, header, botones, imágenes, videos, textos, footer o bloques.

---

### 01. Arquitectura de la información
- Práctica de decidir cómo organizar y estructurar sitios web, de manera que sean comprensibles para poder facilitar el acceso a la información.

**Componentes**
1. organización: cómo se agrupa la información (orden alfabético, cronológico, precios, temas, audiencias, tareas, categorías, ofertas)
2. navegación: cómo se mueve el usuario a través de la información (menú navegación, enlaces contextuales, barra búsqueda, filtros)
3. etiquetado: cómo se nombra y representa la información, lenguaje centrado en el usuario
4. búsqueda: cómo se encuentra la información (motores búsqueda internos, auto navegación)

**Tips para comenzar**
1. Listar contenidos: las secciones y páginas del sitio sin ordenar.
2. Agrupar temas: clasificar contenidos en categorías con sentido.
3. Nombrar categorías: nombre claro pensado para las personas que no conocen el proyecto.
4. Trazar navegación principal: menú principal, navegación secundaria y home como nodo central.

**Mapa navegación**
- Permite realizar una jerarquía comprensible, definiendo categorías principales y secundarias.

**Wireflow**
- Representa visualmente las pantallas por las cuales viaja el usuario durante la navegación de algún sitio o aplicación.


### 02. Sketchs - Wireframe - Prototipo
- Sketch: llevar ideas a un papel.
- Wireframe de baja: estructurar tamaños y dimensiones con bajo nivel de detalles.
- Wireframe de media: comunica jerarquía, nivel medio detalle, utiliza escala de grises para -generar sentido al contenido.
- Wireframe de alta: representación visual y detallada del diseño con contenido real.
- Prototipo: modelo interactivo y funcional, simulando experiencia real.
